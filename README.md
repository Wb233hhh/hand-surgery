# 手部控制的地下诊所手术

毕业设计。玩家用自己的手控制一把手术钳，给躺在铁床上的病人做手术。游戏设定是联机扮演地下医生，靠手术赚钱。现在做到的是单机：一只手带动一把钳子。

引擎是团结 2022.3.62t16（编辑器 1.10.4）。手部识别在 Python 里，不在引擎里。

## 做了什么

### 手部识别

`see_hand.py` 用摄像头和 MediaPipe Hand Landmarker（Tasks API，VIDEO 模式）读手。最多两只手，画面会镜像，并画出骨架。

第一只手会通过 UDP 发到本机 `127.0.0.1:5005`。一条消息是三个数：

```text
x,y,pinch
```

- `x`：食指尖的左右位置，0 在画面左边，1 在右边
- `y`：食指尖的上下位置。已经用 `1 - y` 翻过，画面里向上是大
- `pinch`：拇指尖到食指尖的距离，除以掌宽。并拢接近 0，张开变大

食指对应的关键点是 8，拇指尖是 4，掌宽用关键点 5 和 17。

### 手术场景

团结工程在 `tuanjie/`。场景是 `tuanjie/Assets/Scenes/Surgery.unity`。

- 病人仰面躺在一张脏的铁床上，穿背心和短裤，手臂上有一点血。模型减面到大约 1 万面。摄像机在床的正上方往下看
- 钳子是一把不锈钢止血钳，减面到 9968 面，缩到大约 20 厘米，钳尖朝下，悬在胸口上方
- 播放时 `HandReceiver.cs` 接收上面的 UDP。食指移动整把钳子，范围盖住病人身体。捏合会沿钳口方向缩放，用来模拟张开和夹紧

玩家看到的就是这把钳子，没有医生身体。这是故意的：身份靠房间、病人和以后的钱来表现。

## 怎么运行

先开识别，再在团结里点播放，看 Game 窗口。

```powershell
cd hand-surgery
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirement.txt
python see_hand.py
```

`hand_landmarker.task` 要和 `see_hand.py` 放在一起。摄像头窗口按 `q` 关闭。

用团结 2022.3.62t16 打开 `tuanjie`，打开 `Surgery` 场景，点播放。手在摄像头里移动，钳子会跟着动。

这台电脑上正在使用的工程副本是 `E:\hand-surgery-unity`，和仓库里的 `tuanjie/` 是同一份场景。

## 还差什么

- 第二只手和第二把钳子。画面上能认两只手，但只把第一只手的数据发出去
- 钳口还是一整块模型在缩放，两片钳片不能各自转动
- 没有手术过程：切开、止血、缝合、成功或失败都还没有
- 没有钱、病人状态和计分。地下医生靠手术赚钱这一点还没做
- 没有联机。多人要等单机的手术循环能玩了再做
- 病人模型大约 1 米长，比真人短，还没按真实身体尺寸放大
- 数据只在本机 UDP 上发，没有断线重连，也没有把两只手收成稳定协议
- 浅蓝色病号服那版病人已经弃用，不在这个工程里
